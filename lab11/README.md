This React application retrieves 10 random user profiles from the Random User API using Axios and displays their pictures and details with React Bootstrap.

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000 if the browser does not open automatically.
